# Code of Conduct

This project follows the
[Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep discussion technical.
Harassment, personal attacks and demeaning comments are not tolerated.

Report unacceptable behaviour to the maintainer via a
[private security advisory](https://github.com/mainman94/docker-strapi/security/advisories/new)
or a direct message on GitHub. Reports are handled confidentially.
